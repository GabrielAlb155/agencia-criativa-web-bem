# Agência Criativa Web

Projeto desenvolvido como atividade prática de desenvolvimento web, com foco na organização e refatoração do código utilizando a metodologia **BEM (Block, Element, Modifier)**.

## 📌 Sobre o projeto

A Agência Criativa Web é um site institucional desenvolvido para apresentar os serviços de uma agência digital.

O projeto possui:

* Página inicial
* Seção sobre a agência
* Seção de serviços
* Depoimentos de clientes
* Formulário de contato
* Design responsivo
* Tema visual escuro

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Metodologia BEM
* JavaScript
* Visual Studio Code

## 📐 Organização com BEM

Durante a refatoração, as classes CSS foram organizadas utilizando a metodologia BEM.

Alguns exemplos utilizados no projeto:

```text
.cabecalho
.cabecalho__container
.cabecalho__logo
.menu
.menu__link
.hero
.hero__titulo
.hero__descricao
.servico-card
.servico-card__icone
.servico-card__titulo
.formulario
.formulario__campo
.botao
.botao--primario
.botao--secundario
```

A utilização do BEM ajuda a deixar o CSS mais organizado, previsível e fácil de manter.

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela.

Foram considerados diferentes formatos de visualização:

* Computadores
* Tablets
* Smartphones

Foram utilizadas media queries no CSS para adaptar o layout a telas menores.

## 🎨 Tema escuro

O projeto utiliza uma identidade visual baseada em cores escuras, proporcionando uma aparência moderna e confortável para a visualização.
