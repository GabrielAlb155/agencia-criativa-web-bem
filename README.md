# Agência Criativa Web

Projeto acadêmico de refatoração de CSS utilizando **BEM** e **Sass/SCSS**.

## Objetivos

- Aplicar a metodologia BEM.
- Organizar o CSS em componentes.
- Evitar seletores `#id` no CSS.
- Manter o site responsivo.
- Corrigir a seção de serviços.
- Organizar os arquivos SCSS.
- Gerar o CSS com Sass.

## Estrutura

```text
BEM/
├── index.html
├── package.json
├── README.md
├── css/
│   └── estilos.css
└── scss/
    ├── _base.scss
    ├── _componentes.scss
    ├── _layout.scss
    ├── _mixins.scss
    ├── _variaveis.scss
    └── estilos.scss
